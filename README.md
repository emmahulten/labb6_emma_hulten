# Laboration 6 – Receptsökaren 

## 🌱 Beskrivning
En webbapplikation där användaren kan söka efter recept. Receptdata hämtas från ett externt API och det första receptet i sökresultatet visas på webbsidan.
Om sökningen inte ger några träffar eller om ett fel uppstår visas ett tydligt felmeddelande för användaren.
## 🛠 Tekniker
- HTML
- CSS
- JavaScript
- DummyJSON API
